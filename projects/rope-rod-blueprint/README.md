# 轻绳与轻杆 · 受力之间

一部 60 秒的高中物理 HTML 动画，采用 Claude Opus 5.5 Style 技能中的蓝图／工程制图风格。原创二维制图、中文讲解字幕、原创器乐背景音乐均在本项目中制作。

## 运行

直接打开 `index.html`，点击“开始放映”即可连同音乐播放。页面为独立 HTML，所有资源内嵌，断网可用。浏览器要求首次点击后才能播放声音。支持暂停、重播、时间轴、章节跳转、音量、静音、全屏及键盘操作。

## 内容与适用条件

- 00:00–00:06.25：从一张工程图纸进入轻绳与轻杆。
- 00:06.25–00:16.25：绷紧的理想轻绳沿绳拉，松弛时张力为零。
- 00:16.25–00:26.25：杆可受拉、可受压，限定两端受力的铰接轻杆为二力杆。
- 00:26.25–00:40：水平铰接杆支撑重物，斜绳与水平成 θ，T=G/sinθ，N=G/tanθ。θ=30° 时 T=2G、N=√3G。
- 00:40–00:50：固定连接水平杆端安装理想轻滑轮。同一根轻绳跨过光滑滑轮，静止时两段张力均为 G；两段绳的夹角为 120°，杆对滑轮的作用力为 G，斜向右上，与水平成30°，不沿杆。
- 00:50–01:00：拉杆可换绳、压杆不可换绳，回收至完整图纸。

“自由探究”可调整铰接模型的 θ（20°–65°），实时更新力箭头、数值和闭合力三角形。属于准静态参数对比，不模拟结构加速运动。

## 来源与制作

备课来源、页码和物理边界见 `references/source-notes.md`。原始课件与技能样片保持原样。音乐为项目原创合成室内乐，无第三方录音及网络素材。中文字体使用操作系统字体回退，不分发商业字体。

源码位于 `src/`。`tools/compose_score.py` 用 NumPy 制作配乐；`tools/build.py` 通过 FFmpeg 编码并将配乐、CSS、JS 内嵌为 `index.html`。

## 检查

- `node --check src/film.js`
- `python tools/validate.py`：检查时长、内嵌资源、公式、配乐与图形数据。
- `node tools/verify.cjs`：使用 Playwright Core 和本机 Chromium 浏览器，完整播放60秒、验证离线、拖动、章节、声音、键盘、响应式、探究与控制台错误，并将关键镜头截图存入 `references/`。设置 `PLAYWRIGHT_CORE_PATH` 指向已安装模块。
- `git diff --check`

已执行结果见 `references/verification.json` 和仓库 `docs/handoffs/` 中的交接记录。
