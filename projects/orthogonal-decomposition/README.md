# 向量的正交分解 · 60 秒动画

面向高中生的单页 Canvas 教学动画，用一个可视化例子说明如何把向量拆成沿指定方向的平行分量和与之垂直的分量。页面不依赖外部库、字体或网络资源，可离线打开。

## 运行

直接用现代浏览器打开 `index.html`。动画共 60 秒，包含播放/暂停、重播、拖动进度和章节跳转；系统开启减少动态效果时，页面会停在第一帧。

## 分镜与数学

- 00:00–00:07：提出问题，展示 `v=(4,2)`。
- 00:07–00:16：选定目标方向 `d=(1,1)`。
- 00:16–00:27：从向量终点向目标方向作垂线，得到投影脚点 `(3,3)`。
- 00:27–00:39：展示剩余分量 `(1,−1)`，并首尾相接还原原向量。
- 00:39–00:50：用点积 `3×1+3×(−1)=0` 验证垂直。
- 00:50–01:00：给出任意非零方向 `d` 的通用公式并回顾。

平行分量公式为 `v‖=((v·d)/(d·d))d`，垂直分量为 `v⊥=v−v‖`。本页用动态画面、字幕与公式讲解，没有录制语音。

## 检查

- 打开页面并播放完整 60 秒，确认字幕、图形和进度同步。
- 拖动时间轴并点击各章节，确认可定位到对应分镜。
- 在窄屏视口检查公式、字幕与播放控件没有裁切或重叠。
- 断网后打开页面，确认动画仍可运行。
