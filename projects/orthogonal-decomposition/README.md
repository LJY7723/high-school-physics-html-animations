# 向量的正交分解 · 60 秒动画

面向高中生的单页 Canvas 教学动画，用坐标轴上的分量说明如何把向量拆成 x 方向和 y 方向的两个互相垂直的分量。页面不依赖外部库、字体或网络资源，可离线打开。

## 运行

直接用现代浏览器打开 `index.html`。动画共 60 秒，包含播放/暂停、重播、拖动进度和章节跳转；系统开启减少动态效果时，页面会停在第一帧。

## 分镜与数学

- 00:00–00:07：提出问题，展示 $\vec{a}=(4,2)$。
- 00:07–00:16：选定 x 轴和 y 轴，两条坐标轴互相垂直。
- 00:16–00:27：从向量终点向 x 轴作垂线，得到脚点 $P=(4,0)$ 和 x 方向分量 $\vec{a}_1=(4,0)$。
- 00:27–00:39：补出 y 方向分量 $\vec{a}_2=(0,2)$，并首尾相接还原原向量。
- 00:39–00:50：用点积 `4×0+0×2=0` 验证两个分量垂直。
- 00:50–01:00：用高中常见坐标形式写出 $\vec{a}=x\vec{i}+y\vec{j}$，其中 $\vec{a}_1=x\vec{i}$、$\vec{a}_2=y\vec{j}$。

本页使用向量箭头和坐标分量记号，避免引入超出本节的任意方向投影公式；用动态画面、字幕与公式讲解，没有录制语音。

## 检查

- 打开页面并播放完整 60 秒，确认字幕、图形和进度同步。
- 拖动时间轴并点击各章节，确认可定位到对应分镜。
- 在窄屏视口检查公式、字幕与播放控件没有裁切或重叠。
- 断网后打开页面，确认动画仍可运行。
